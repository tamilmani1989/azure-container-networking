REQUIREMENTS:

1. curl lib
2. xml lib

Installing Curl lib:
--------------------

sudo apt-get install libcurl3-dev

Installing xml lib:
-------------------

sudo apt-get install libxml2-dev

Build:
------

1. Go to root directory of the project.
2. Run buildclean.sh
3. Run buildall.sh. This builds azure overlay, network client library and test code
